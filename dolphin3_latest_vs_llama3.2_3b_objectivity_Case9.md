Given a dynamic, self-organizing network of autonomous agents tasked with optimizing resource allocation across a geographically distributed, heterogeneous computing infrastructure, the design of a robust and scalable system for inter-agent communication and coordination hinges on several key principles.

Firstly, the system must employ a decentralized communication protocol that allows agents to exchange information without relying on a centralized hub. This can be achieved through a peer-to-peer (P2P) network topology, where each agent acts as both a client and a server, facilitating direct communication between agents. This approach ensures that individual agent autonomy is maintained, as each agent has control over its own communication and resource allocation decisions.

Secondly, to ensure collective system-level efficiency, the system should implement a distributed consensus algorithm. This algorithm enables agents to reach a consensus on resource allocation decisions without requiring a centralized authority. One example of such an algorithm is the Paxos algorithm, which allows a group of agents to agree on a single value without revealing their individual preferences.

Thirdly, to remain resilient to unpredictable failures and evolving resource demands, the system should incorporate fault tolerance mechanisms. One such mechanism is the use of redundant agents, where multiple agents can perform the same task to ensure that the system continues to function even if one or more agents fail. Additionally, the system should employ a load balancing mechanism to distribute resource demands evenly across agents, preventing any single agent from becoming a bottleneck.

Lastly, to optimize resource allocation, the system should utilize a market-based approach. In this approach, agents can trade resources with each other based on supply and demand dynamics. This allows for efficient resource allocation, as agents can make informed decisions based on real-time market conditions.

In conclusion, a robust and scalable system for inter-agent communication and coordination in a dynamic, self-organizing network can be achieved through the use of a decentralized communication protocol, distributed consensus algorithm, fault tolerance mechanisms, and a market-based approach to resource allocation. These principles ensure both individual agent autonomy and collective system-level efficiency while remaining resilient to unpredictable failures and evolving resource demands.
